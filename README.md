#  Магазин 

## 📋 Описание проекта

Веб-приложение интернет-магазина с использованием Flask и Bootstrap.

## 🎯 Функционал

- ✅ Главная страница с товарами
- ✅ Страница "Контакты" с формой обратной связи
- ✅ POST-обработка формы с выводом в консоль
- ✅ Обработка ошибок 404 и 500
- ✅ Левое боковое меню
- ✅ Адаптивный дизайн

## 🚀 Установка и запуск

+ Установите на свой компьютер GitHub.
+ Клонируйте репозиторий с GitHub  с помощью веб-URL.
+ https://github.com/marfuta07/DZ_21.2/pull/1
+ Запустить приложение python manage.py

DZ_21.2/

+ app-# Основная папка приложения 
+ static- # Статические файлы (CSS, JS, изображения)

+ templates/                          # HTML-шаблоны для всех страниц
+ base.html                      # Базовый шаблон с меню, хедером, футером
+ index.html                     # Главная страница с товарами (3 шт.)
+ contacts.html                  # Страница контактов с формой обратной связи
+ category.html                  # Страница категории с товарами (4 шт.)
+ 404.html                       # Страница ошибки 404 (не найдено)
+ 500.html                       # Страница ошибки 500 (ошибка сервера)


 
+ views.py - # ПЕРЕКЛЮЧАТЕЛЬ режимов работы
+ views_mode1.py - # Режим 1: Полноценный сайт 
+  views_mode2.py - # Режим 2: Задание 2 (render_template)
+ views_mode3.py  - # Режим 3: Задание 2 (with open)

+ manage.py-# Точка входа для запуска сервера
